# 🧠 AI Question Answering Streamlit App

A simple AI-powered Question Answering web application built using **Streamlit** and **Hugging Face Transformers**.  
This project allows users to input a context and ask questions to get intelligent answers generated by a pre-trained language model.

---

## 🚀 Features

- 📝 Enter custom context text
- ❓ Ask questions based on the context
- 🤖 AI-powered answers using a transformer model
- ⚡ Fast inference with cached model loading
- 🎯 Simple and interactive Streamlit UI

---

## 🛠️ Tech Stack

- Python 🐍
- Streamlit 🎈
- Hugging Face Transformers 🤗
- Pretrained Model: `timpal0l/mdeberta-v3-base-squad2`
